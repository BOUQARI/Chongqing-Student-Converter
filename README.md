# 🇨🇳 Chongqing Student Converter (v3.0)
**The Ultimate Financial Companion for International Students in Chongqing.**

## 📌 Overview
This application is a professional-grade currency converter specifically designed for Tunisian students pursuing their studies in **Chongqing** (CQUST, CQUPT, etc.). It addresses the daily struggle of currency mental math by providing a seamless, real-time bridge between **TND** and **CNY**.

## 🚀 Key Features
- **Live Exchange API:** Integrates with real-time financial data for 100% accuracy.
- **Multilingual Support:** One-click toggle between **English** and **Mandarin Chinese** (简体中文).
- **Dual-Theme Engine:** Professional **Dark Mode** and **Light Mode** for eye comfort.
- **Bi-directional Conversion:** Switch instantly between "Tunisian Dinar to Yuan" and vice-versa.
- **Modern UI/UX:** Flat, minimalistic design inspired by modern OS ecosystems.

## 🛠 Tech Stack
- **Core:** Python 3.x
- **Networking:** REST API (Requests library)
- **Interface:** Tkinter (Advanced State Management)
